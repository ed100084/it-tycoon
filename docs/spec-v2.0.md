# IT-Tycoon v2.0 設計規格書

## 核心定位

「從 Y2K 時代的第一台 Dell 伺服器，到 AI 基礎設施競賽的 H100 叢集——你要在二十五年的科技巨變中，同時應付採購簽呈、資安事件、SLA 違約賠償，還有每一個讓 IT 預算蒸發的黑天鵝。」

核心張力：**歷史科技演進感 ↔ 現實官僚摩擦 ↔ 外部宏觀不確定性 ↔ P&L 壓力**

## Section 1：財務模型（P&L）

### 1.1 損益結構總覽

```
月度淨利 = 月度總收入 − 月度總支出

月度總收入：
  + 主機代管收入
  + VPS/虛擬主機收入
  + SaaS 平台服務收入
  + 頻寬/CDN 服務收入（2004年後可解鎖）
  + 管理服務（MSP）收入（2006年後可解鎖）
  + DRaaS 災難復原服務收入（2010年後可解鎖）
  + 資安服務（MSSP）收入（2010年後可解鎖）
  + AI/ML 運算服務收入（2018年後可解鎖）
  + 專業服務/顧問收入（一次性，2002年後）
  + 培訓/認證收入（一次性/季，2003年後）

月度總支出：
  − 硬體折舊（月攤提）
  − 軟體授權費（年費型/季付）
  − 電力費用（含 PUE 效率損耗）
  − 頻寬費用
  − 人力成本（薪資+福利）
  − 設施租金/折舊
  − 維護合約費用（硬體延保+軟體支援）
  − 保險費
  − 合規費用
  − SLA 違約賠償（不定期，依事件觸發）
```

### 1.2 收入來源詳細

#### 循環收入（訂閱型）

| 服務類型 | 解鎖條件 | 合約週期 | SLA 等級 | 月收入範圍（NT$）| SLA 違約賠償 |
|---------|---------|---------|---------|----------------|------------|
| 主機代管 (Colocation) | 開局 | 1–3 年 | 99.5% | $1,000–$50,000 | 月費 10–100% |
| VPS/虛擬主機 | 擁有 T2+ × 5 | 月租/年租 | 99.9% | $500–$20,000 | 月費 10–50% |
| SaaS 平台服務 | 擁有 T3+ × 3 + 2005年後 | 年租 | 99.95% | $5,000–$200,000 | 月費 20–200% |
| 頻寬/CDN 服務 | 擁有 T2+ × 2 + 2004年後 | 月租/年租 | 99.9% | $2,000–$150,000 | 月費 10–50% |
| 管理服務 MSP | T3+ × 2 + 員工 ≥ 5 + 2006年後 | 年租 | 99.95% | $8,000–$300,000 | 月費 20–150% |
| DRaaS | Prestige 1 後 + 2010年後 | 年租 | 99.99% | $2,000–$100,000 | 月費 50–500% |
| 資安服務 MSSP | ISO 27001 認證 + 2010年後 | 年租 | 99.99% | $5,000–$200,000 | 月費 30–200% |
| AI/ML 運算 | 擁有 GPU 節點 + 2018年後 | 計時/月租 | 99.9% | $10,000–$500,000 | 月費 15–100% |

> **頻寬/CDN 服務**：對上游 ISP 購買頻寬（成本），再轉售給客戶（收入）。轉售溢價空間隨時代縮小，需靠量取勝或升級至 CDN PoP 架構。

> **MSP（Managed Service Provider）**：代客戶管理基礎設施、OS 修補、監控告警。每份 MSP 合約消耗 0.5 名工程師的工時配額。

> **MSSP（Managed Security Service Provider）**：24×7 SOC 監控、事件回應、合規報告。需資安分析師配置（每合約 0.5 人），違約賠償最重（客戶視資安為生死問題）。

#### 一次性收入（專案型）

| 服務類型 | 解鎖條件 | 週期 | 單案收入範圍（NT$）| 備注 |
|---------|---------|------|-----------------|------|
| 專業服務/顧問 | 工程師 ≥ 2 + 2002年後 | 一次性（1–3 個月）| $5,000–$500,000 | 消耗工程師工時；無 SLA 違約賠償 |
| 培訓/認證 | 2003年後 | 一次性/季 | $500–$20,000 | 低工時消耗；提升客戶滿意度 +2 |

> **專業服務**範疇：系統遷移、架構設計、DR 演練、容量規劃。高單價但工時密集，景氣衰退期反而需求增加（企業削本找外援）。

> **培訓/認證**：面向客戶 IT 人員開設課程（VMware、Linux、資安認知）。收入小但邊際成本低，且有助於鎖定客戶生態圈。

**合約生命週期（循環收入）：**
```
提案 → 談判（可選擇加碼 SLA 換取更高月費）→ 簽約 → 履約 → 續約/流失
```

合約到期前 1 個月遊戲內時間會提示續約談判，高滿意度（>80）自動續約成功率 +40%。

**專案生命週期（一次性收入）：**
```
RFP 接案 → 報價 → 交付（消耗工時）→ 驗收付款 → （可轉換為 MSP 合約）
```

完成專業服務案件後，客戶滿意度 ≥ 85 時，有 30% 機率自動提出轉簽 MSP 合約詢問。

### 1.3 支出項目詳細

#### 硬體折舊

```
月攤提 = 硬體採購價 / 折舊年限（月數）

折舊年限：
  伺服器類     5 年（60 個月）
  網路設備     7 年（84 個月）
  儲存設備     5 年（60 個月）
  UPS/電源     10 年（120 個月）

殘值 = 10%（折舊到期後停止攤提但仍計 EOL 風險）
```

#### 電力成本

```
月電費 = Σ(設備功耗 W) × 744 小時 × 電費單價(NT$/kWh) × PUE / 1000

電費單價：
  2000–2010 年：NT$2.5/kWh
  2011–2020 年：NT$3.0/kWh（日本311後能源轉型）
  2021–2022 年：NT$3.2/kWh
  2022–2025 年：NT$4.0/kWh（俄烏戰爭能源成本上升）
  
econElecMod 乘數由國際事件動態調整（範圍 0.8–2.5）
```

#### 頻寬成本

```
月頻寬費 = 實際使用頻寬(Mbps) × 單價(NT$/Mbps/月)

頻寬單價（隨時代下降）：
  2000–2004 年：NT$2,000/Mbps
  2005–2009 年：NT$500/Mbps
  2010–2014 年：NT$100/Mbps
  2015–2019 年：NT$20/Mbps
  2020+ 年：NT$5/Mbps

頻寬需求 = Σ 各合約服務的頻寬分配
```

#### 人力成本

```
月人力成本 = Σ 各員工月薪 × 1.3（法定福利、勞健保、退休金提撥）

月薪基準（台灣市場，隨時代通膨調整）：
  NOC 技術員：NT$35,000–45,000（2000年基準）
  系統工程師：NT$50,000–70,000
  資安分析師：NT$60,000–80,000
  雲端架構師：NT$80,000–120,000（2010年後職位）
  AI 工程師：NT$100,000–200,000（2018年後職位）

每年薪資通膨 2–3%（依通膨率調整）
```

#### 維護合約費

```
月維護費 = Σ(設備原始採購價 × 維護費率 / 12)

維護費率：
  原廠保固內（3年）：含購買價，月費為 0
  延保 (Next Business Day)：購買價 × 8%/年
  延保 (4-Hour Response)：購買價 × 12%/年
  EOL 設備（停產後）：購買價 × 20%/年（第三方維護）
  EOS 設備（軟體停止支援）：另加資安合規保險費
```

## Section 2：三層貨幣

| 貨幣 | 解鎖條件 | 效果 | Prestige 後 |
|------|----------|------|-------------|
| 算力幣（₡）| 開局 | 主貨幣，代表服務收入；購買一切 | Tier 1 歸零 |
| 聲望（Rep）| Prestige 1 後 | +2%/點全域產出；解鎖科技樹 | Tier 2 重置 |
| 影響力（Inf）| Prestige 2 後 | +5%/點全域產出 + 洗點券 | 永久保留 |

### 收入計算公式

```
月度淨收入（₡）= 月度總合約收入
               × 滿意度加成 (1 + satisfaction/200)
               × Reputation 加成 (1 + rep × 0.02)
               × Influence 加成 (1 + inf × 0.05)
               × 人力效率係數 (staffEfficiency, 0.5–1.2)
               × 經濟環境係數 (econFactor, 0.7–1.3)
               × 事件影響係數 (incidentFactor, 0.0–1.0)
               × 異地備援加成 (若啟動 ×1.25)
               − 月度總支出

每秒 CPS = 月度淨收入 / (30 × 24 × 3600)
```

#### 人力效率係數 (staffEfficiency)

```
managedU    = Σ 各工程師可管理 U 數
totalU      = 全部已部署硬體 U 數
coverageRatio = managedU / totalU

if coverageRatio ≥ 1.0 → staffEfficiency = 1.0 + min(coverageRatio − 1.0, 0.2)
if coverageRatio ≥ 0.7 → staffEfficiency = 0.7 + (coverageRatio − 0.7) × 1.0
if coverageRatio < 0.7  → staffEfficiency = max(0.5, coverageRatio × 0.71)
```

#### 經濟環境係數 (econFactor)

```
econFactor = businessCycleMod × inflationMod × macroEventMod

businessCycleMod：繁榮=1.15, 正常=1.00, 衰退=0.85, 蕭條=0.70
inflationMod = 1 / (1 + inflationRate)
macroEventMod = 由歷史事件動態調整（見 Section 12）
```

### 3.4 採購成本公式

```
實際採購價 = 基礎採購價 × 1.15^(已擁有同型台數) × econHardwareMod × exchangeRateMod

econHardwareMod：受景氣循環、晶片短缺等國際事件影響（0.7–2.5）
exchangeRateMod：匯率波動影響進口設備（0.9–1.3）

ODM 品牌（Supermicro）基礎採購價 × 0.75（性價比高，但管理工具加成 −10%）
品牌溢價（IBM, Cisco UCS）基礎採購價 × 1.25（管理工具加成 +10%）
```

### 4.6 EOL/EOS 生命週期效果

```
EOL（End of Life）= 硬體停止銷售，進入延保階段
EOS（End of Support）= 軟體停止安全更新，資安風險上升

硬體 EOL 效果：
  EOL 後第 1 年：故障率 ×1.5、維護費 ×1.5
  EOL 後第 2 年：故障率 ×2.0、維護費 ×2.0
  EOL 後第 3 年+：故障率 ×3.0、維護費 ×3.0（建議汰換）

軟體 EOS 效果：
  EOS 當月：出現警告通知，complianceMod ×1.3
  EOS 後第 1 季：資安事件觸發率 +20%、complianceMod ×1.5
  EOS 後第 2 季：資安事件觸發率 +50%、complianceMod ×2.0、稽核風險 +30%
  EOS 後第 3 季+：資安事件觸發率 +100%、complianceMod ×3.0、強制合規罰款

汰換提示：
  EOL/EOS 前 3 個月：UI 顯示黃色警告
  EOL/EOS 後：UI 顯示紅色警告，並在設備圖示上顯示骷髏頭標誌
```

**EOL 連鎖效果範例：**
```
EOL 硬體 → 故障率上升 → P2/P1 事件頻繁 → 工程師被事件佔用 
→ staffEfficiency 下降 → SLA 違約風險上升 → 客戶滿意度下降 
→ 合約流失 → 收入下降 → P&L 惡化
```

**APT 偵測機制：**
- 無 SOC：需玩家手動點擊「安全掃描」（每次消耗月收入 1%）

- 有零信任架構：APT 觸發率 −30%
- 有 SIEM：偵測率 +40%，並可回溯攻擊路徑

**資料外洩通報流程（法規要求）：**
1. 發現事件 → 點擊「啟動調查」
2. 調查期間（60 秒）需指派至少 1 名 E3+ 工程師
3. 調查完成 → 點擊「通報主管機關」（72 小時內，對應 3.6 分鐘現實時間）
4. 通報完成 → 滿意度逐步恢復（每分鐘 +1）
5. 未在時限內通報 → Rep −5、觸發法規稽核 + 罰款 NT$ 200–500萬

### 14.5 事件升級機制

```
未處理時間 > 處理時限 → 50% 機率升級（P4→P3→P2→P1）
P1 未處理超過 30 秒 → 全域停擺（所有服務月收入 = 0 直到處理完畢）
多事件同時發生 → 處理力分散，形成「事件風暴」
EOS 軟體期間 → 事件升級速度 ×1.5
EOL 硬體故障 → 若未在 P2 時限處理，SLA 違約自動觸發
```

**SLA 違約連鎖效果：**
```
P1 事件超時 → SLA 違約 → 合約賠償（月費 10–500%）
→ 滿意度 −10 → 合約續簽風險上升 → 年度合約流失
→ 月收入下降 → P&L 惡化 → 無法投資升級
→ 更多 EOL 設備無法汰換 → 故障率繼續上升（惡性循環）
```

### 關鍵連動鏈說明

**1. EOL 連鎖崩潰路徑**
```
EOL 硬體不汰換 → 故障率 ×2–3 → P2/P1 事件頻發
→ 工程師被佔用 → staffEfficiency 下降
→ SLA 違約觸發 → 合約賠償（P&L 惡化）
→ 客戶滿意度下降 → 合約流失
→ 月收入下降 → 無力汰換硬體（惡性循環）
```

**2. EOS 資安連鎖**
```
EOS 軟體不升級 → complianceMod 上升 → 資安事件頻率暴增
→ 勒索軟體/資料外洩觸發 → SLA 違約 + 合約賠償
→ 滿意度 −15 to −30 → 大量合約流失
→ Rep 下降 → 科技樹解鎖變慢（成長停滯）
```

**3. 歷史事件 × 準備度**
```
歷史事件提前預警（UI 顯示倒計時）→ 玩家有時間備貨/升級/買保險
→ 有備而來 = 事件變機遇（抓住需求暴增）
→ 沒有準備 = 事件成危機（成本暴增、服務中斷）
```

**4. AI 時代轉型壓力**
```
2023 年後無 GPU 節點 → AI 合約競標資格喪失
→ 雲端競爭 × 無差異化 → VPS 合約持續流失
→ 月收入下滑 → P&L 惡化
→ 無法投資 GPU 設備（AI 設備昂貴）→ 轉型困難
（建議 2021 年就開始籌備 GPU 基礎設施）
```

**5. P&L × 歷史周期**
```
金融海嘯（2008）→ 客戶削減 IT 預算 → 月收入 −25–40%
→ 若固定成本過高（人力+租金+授權）→ 月虧損
→ 被迫裁員 → staffEfficiency 崩潰
→ 故障率上升 → 形成雙重壓力（收入跌+成本漲）
```

## Section 19：待決事項

### 遊戲設計
1. 歷史硬體型號清單完整性：2005–2015 年段需補充更多台灣常見品牌（廣達、緯穎、英業達 ODM 設備）
2. 合約談判小遊戲設計：月費上限 vs. SLA 等級的 trade-off 介面 UX
3. Prestige 後歷史時鐘是否重置：目前設計重置至 2000 年，但歷史事件是否重新觸發？建議：重置時間軸但事件觸發強度依 Prestige 次數遞增
4. AI 時代 End Game loop：2025 年後的遊戲目標需要更多設計

### 數值平衡
5. P&L 模型的折舊攤提 vs. 現金流：玩家可能因大量採購造成帳上有錢但現金流為負的情況，需要設計「破產保護」機制
6. 電費單價時代曲線：台灣電費實際上在 2022 年前相對平穩，2022 後才大漲，曲線需要更貼近現實
7. 通膨率 × 薪資調整：工程師薪資每年依通膨調整可能造成後期人力成本失控，需要設計薪資上限或生產力連動
8. AI 服務月費增長曲線：2023+ 的 AI 合約月費每月 +2% 是否過高？需要模擬 10 年後的收入規模

### 系統整合
9. 歷史事件「強制觸發」vs.「機率觸發」邊界：哪些事件必定發生（WannaCry）、哪些是機率事件（晶片短缺強度）？
10. Broadcom 收購 VMware 事件（2023）：是否應強制觸發科技樹重選？目前設計是月授權費暴增，但玩家可能已有其他虛擬化平台
11. EOL/EOS 過渡期 UX：設備從黃色警告到紅色骷髏頭的視覺轉換需要漸進設計，避免玩家「猝死」
12. SLA 違約賠償累積上限：若同時多個 P1 事件，賠償金總額可能超過月收入，需要設計合理上限（例如最多一個月總合約收入的 300%）
