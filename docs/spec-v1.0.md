# IT-Tycoon v1.0 設計規格書

## 核心定位

「一個雲端服務提供商的擴張模擬，但你還是要寫簽呈、應付稽核、處理跨院區協調的官僚現實。」

核心張力：**高科技擴張感 ↔ 官僚日常摩擦**

---

## 玩家旅程

| 階段 | 時間 | 主要行為 |
|------|------|----------|
| Onboarding | 0–15 min | 點擊產生 Compute、買第一台硬體 |
| Early Game | 15 min–1.5 h | 部署硬體陣列、開始管電費 |
| Mid Game | 1.5–3 h | 多區域配置、應付稽核、跑簽呈 |
| First Prestige | ~3–4 h | 資料中心重建，解鎖 Reputation + 科技樹 |
| Late Game | 4 h–數天 | 科技樹探索、多次 prestige |
| End Game | 數週 | 極限數字、成就全收集 |

---

## 三層貨幣

| 貨幣 | 解鎖條件 | 效果 | Prestige 後 |
|------|----------|------|-------------|
| Compute（算力）| 開局 | 主貨幣，購買一切 | Tier 1 歸零 |
| Reputation（聲望）| Prestige 1 後 | +2%/點全域產出 | Tier 2 重置 |
| Influence（影響力）| Prestige 2 後 | +5%/點全域產出 + 洗點券 | 永久保留 |

## 電費系統

```
每秒電費 = 耗電(W) × 電價(0.001) × PUE
```

餘額不足付電費 → **全部停機**（需手動點擊產生緊急算力重啟）

### PUE 升級路徑

| 等級 | 名稱 | PUE | 成本 |
|------|------|-----|------|
| 0 | 開放式機架 | 2.00 | — |
| 1 | 基礎空調 | 1.80 | 5,000 |
| 2 | 熱通道封閉 | 1.60 | 50,000 |
| 3 | 冰水主機 | 1.40 | 500,000 |
| 4 | In-Row 冷卻 | 1.25 | 5,000,000 |
| 5 | 液冷系統 | 1.10 | 50,000,000 |
| 6 | 浸沒式冷卻 | 1.05 | 500,000,000 |

## 機房空間 (3 區域)

| 區域 | 解鎖條件 | 容量 | CPS 加成 | 電耗加成 |
|------|----------|------|---------|---------|
| 北區 | 開局 | 100U | ×1.00 | ×1.00 |
| 中區 | Compute ≥ 1M | 500U | ×1.15 | ×1.00 |
| 南區 | Compute ≥ 100M | 2,000U | ×1.30 | ×1.20 |

- 三區都 ≥ 50% 使用率 → **異地備援 buff +25%**
- 可擴建：成本 = 當前容量 × 100，增量 = 容量 × 0.5

| 方式 | 價格 | 等待時間 |
|------|------|---------|
| 快速採購 | 標準價 | 即時 |

## 稽核事件（每 8–12 分鐘隨機）

| 類型 | 中文名 | 效果（通過/失敗）|
|------|--------|----------------|
| ISO 27001 | ISO 稽核 | 暫停 60s；通過 +1 Rep / 失敗 −20% 5分鐘 |
| 衛福部資安法 | 法規稽核 | 消耗 5% Compute；通過 +30% 5分鐘 / 失敗 −10 Rep |
| 客戶突襲 | 客戶訪查 | 二選一，影響滿意度 |
| 資安演練 | 演練（Prestige 1 後）| 多選題；通過 +1 Influence |

## 滿意度

- 範圍：0–100（預設 75）
- 效果：每點 +0.5% 全域產出
- 由「客戶突襲」稽核事件影響

## 科技樹 (DAG，v1.0 共 20 節點)

使用 **Reputation** 購買。節點分類：

| 分類 | 範例節點 |
|------|---------|
| 產出強化 | 超頻協定、量子糾錯 |
| 效能優化 | NVMe 快取、GPU 加速 |
| 成本控管 | 電力期貨合約、節能認證 |
| 空間革新 | 高密度機架、模組化擴建 |
| 管理升級 | 流程自動化、稽核準備系統 |
| 規模經濟 | 批量採購協議 |
| 離線強化 | 無人值守運維 |
| 隱藏節點 | 需特定條件觸發 |

有**互斥節點**防止單一最佳解。

## Prestige 系統

### Tier 1「資料中心重建」
- 條件：totalEarned ≥ 1e10 **且** 擁有至少 1 台 T5
- 效果：`Rep = floor(sqrt(totalEarned / 1e9))`
- 重置：Compute 歸零、硬體清空，保留 Reputation

### Tier 2「IPO」
- 條件：累積 500 Reputation
- 效果：`Influence = floor(sqrt(totalRep / 100))`
- 重置：Compute + Reputation 歸零，保留 Influence
